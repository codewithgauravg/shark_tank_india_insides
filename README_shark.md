# 🦈 Shark Tank India Data Analysis

## 📌 Project Overview

This project analyzes the Shark Tank India dataset to uncover trends in startup funding, industries, investments, and presenter demographics. The analysis was performed using Python and various data analysis libraries to generate meaningful business insights.

---

## 🎯 Project Objective

The main objective of this project is to:

* Analyze startup pitches presented on Shark Tank India.
* Identify funding and investment patterns.
* Explore industry-wise startup distribution.
* Understand presenter demographics.
* Generate actionable insights through data visualization.

---

## 📊 Dataset Information

Dataset Name: Shark Tank India Dataset

Total Records: 634 Startup Pitches

Key Features:

* Startup Name
* Episode Number
* Industry
* Pitch Number
* Season Number
* Anchor
* Company Website
* Number of Presenters
* Male Presenters
* Female Presenters
* Started In
* Original Air Date

---

## 🧹 Data Cleaning Process

The following data cleaning steps were performed:

* Checked dataset structure using `.info()`
* Identified missing values using `.isnull().sum()`
* Handled null values in presenter-related columns
* Verified data types of columns
* Removed unnecessary inconsistencies
* Prepared dataset for analysis and visualization

---

## 📈 Exploratory Data Analysis (EDA)

The following analyses were performed:

### Industry Analysis

* Most common startup industries
* Industry-wise startup distribution

### Presenter Analysis

* Male vs Female presenter participation
* Number of presenters per pitch

### Season Analysis

* Startup pitches across seasons
* Season-wise growth trends

### Funding Trends

* Analysis of investment opportunities
* Startup participation patterns

---

## 🔍 Key Insights

* Certain industries dominate startup pitches.
* Most startups are presented by small teams.
* Male presenters appear more frequently than female presenters.
* Startup participation increased across seasons.
* Some industries attract significantly more investor attention.
